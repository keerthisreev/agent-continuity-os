How recovery works

The six stages of a protected run. The timeline on a result page shows only the stages that run actually recorded — a stage with no record is shown as “not recorded,” never as a success.

1. DetectionContracts check each output; a violation or anomaly is recorded with its tick.
2. QuarantineThe suspect role is fenced; its generation is revoked.
3. Epoch fencingEvery write must present the current generation, or the store refuses it.
4. ReconciliationCompleted effects are checked against the journal before any retry.
5. RecoveryA standby resumes from the incident-scoped checkpoint.
6. VerificationEffects, duplicates prevented, and disposition are recorded in the receipt.

What is simulated, what is executed

Simulated

Provider backends, ack loss, fault modes, agent outputs (scripted). TSFD/TRV are logical ticks, not wall-clock.

Executed

Sentinel checks, canary oracles, epoch fencing, journal recovery decisions, checkpoint resume, ledger entries, receipts.
